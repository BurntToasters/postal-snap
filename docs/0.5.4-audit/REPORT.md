# Postal Snap 0.5.4 audit

The audit began on November 25, 2026 (Pacific) at `c84824a2048c82757ad98f072020c9c6c25e2c48`. The comparison release is `v0.5.3` at `5ad7bb6`. Both baselines use isolated copies. The starting branch was clean.

## Candidate and release decision

Twenty-three findings were recorded. Seventeen preceded the workstation interruption. Six more came from exercising the composer, rule editor and opened-message viewer. The working tree has source SHA-256 `783c06ac1875216182c81817e93be1c74412221c1122af5e10d55fbda9604975`. It contains 1,218 inventoried source paths, including 102 modified paths and 178 additions. Of the additions, 168 belong to the verified upstream serde_with source package. The digest includes source paths, file bytes and modes. It excludes ignored build outputs and this audit directory to keep the report independent of its own fingerprint.

## What changed in mail and storage

- **Rule editing.** New condition and action rows keep their initial identity while account data loads. Rule fields capture the entered value before updating the draft. An earlier candidate lost keyboard focus on the first character in all 12 browser, density and text-size combinations. The same 12 cases passed after the fix, including the two-condition preview request.
- **Arrival rules and notifications.** Every enabled rule evaluates the same oldest-first page of up to 100 pending unread arrivals in the effective Inbox. Completed nonmatches retire. Transient failures remain pending. Manual retroactive rules keep their existing matching path. The first repair passed the overlap case but still scanned 600,017 SQLite VM steps to find an empty rule page in a 100,000-message account. The v46 queries use dedicated partial indexes for pending rules and pending notifications. The joined rule query now takes 15 steps at 1,000, 10,000 and 100,000 messages.
- **Folder counts.** The list uses authoritative STATUS counts directly and calculates only missing local counts. Tests cover mixed totals, optimistic changes, snoozes, pending moves, role assignments and isolated accounts. On the 100,000-envelope fixture, the old account query took 6,800,152 SQLite VM steps. The revised source-derived query took 103 steps at all three sizes. Median time at the largest size fell from 118 ms to 0.0048 ms on this host.
- **Failed offline changes.** Users can review and confirm selected failures per account. Dismissal checks the account, operation ID and opaque failure token in one transaction. Native and browser regressions cover changed failures, reused integer IDs, cancellation, retry, redacted errors and return of keyboard focus. The operation name and number are announced at all three densities, including 200% text.
- **Bulk operations across accounts.** Selection, reader and error updates are scoped to the account and view that initiated the action. A partial bulk result no longer takes the user out of selection mode in a different account.
- **Moved rows and search.** When a move is refused, the list reconciles against the active mailbox or submitted search, including a STATUS refresh and changes made to other rows. Reconciliation preserves an unsubmitted search edit. Continuation now distinguishes an interrupted, resumable search from a finished search that permanently skipped older matches.
- **Mail integration and migrations.** GreenMail 2.1.11 and the local Bridge simulation passed all 35 runner stages on the repaired mail engine. They cover legacy rule-target migration, finite Undo holds, offline cancel, expiry and a single restart replay. A separately populated v43 database reopened twice at v46 with its queued change, unsent message and both attachment owners intact. A native launch tested the v1 migration on both macOS CPU architectures.

## UI, security and maintenance

- **Opened email and links.** Native open tokens survive listener registration, multiple opens and remounts. A failed token read leaves later opens available. The Flatpak desktop entry declares RFC 822 support and passes desktop-file validation. A nested iframe click in Chromium now uses the element's own document realm. A separate macOS WKWebView probe observed both HTTPS and mailto link callbacks from native pointer events in the production frame policy. Installed OS file associations still need verification.
- **Rich compose.** Removing one managed inline attachment removes all its editor occurrences. Two independent pastes of identical bytes retain separate content IDs. Reopening a saved draft preserves that identity. The regressions also check that editor Undo cannot revive a removed attachment.
- **Composer formatting.** Native font and size fields keep keyboard focus while applying formatting to the selection or caret. Pointer changes can return focus to the editor. The toolbar subscribes to formatting state so its displayed choices and pressed buttons follow editor transactions.
- **Native frame links.** The opened-message viewer and reader register their link handlers before the first paint. One native event now produces exactly one URL inspection, confirmation and open. The first-commit check failed in both engines before the change.
- **Modal focus.** A dialog establishes its keyboard trap and initial focus during layout. A subsequent full run found that React effect replay could replace the original Settings opener with the dialog’s Close button. The hook now remembers the external opener across replay. Full browser traces captured the failure in both Windows and macOS user-agent variants. Focused checks cover the opener after close, Credits over Settings, an open composer menu and the opened-file viewer.
- **Dependencies and packaging.** Both npm vulnerability scopes and the strict Cargo audit passed. The Rust lock contains 701 packages. The audit removed Chrono and preserved stored timestamp, date-header, local-time and IMAP behavior. The project now carries the published serde_with 3.24.0 source with its unused Chrono adapter removed. The patch's origin, licensing and upgrade obligation are in the [dependency audit](dependencies.md).
- **Baseline reliability.** Two historically impossible mail fixtures and incomplete browser instrumentation concealed failures. The repaired suite exercises the historical SQLite layout, real TLS services, the latest and previous application document, and source-only browser cases. The configured coverage thresholds are 94% lines, 74% statements, 68% branches and 79% functions.
