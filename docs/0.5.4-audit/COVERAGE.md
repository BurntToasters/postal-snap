### Large folders and repeated UI use

The folder-count fixture seeds 1,000, 10,000 and 100,000 envelopes and exercises authoritative, absent and mixed server counts. A separate probe runs the SQL from the application's automatic-rule path against a populated account with no pending arrivals. It keeps the effective-role join, unread and pending-move filters, sort order and parameter bindings. The simpler migration test for the presence of an index missed a production query-plan regression.

The browser timing fixture performs the same five actions on v0.5.3 and the 0.5.4 starting branch. A second Chromium fixture opens and closes account Settings 65 times, removes the mock IPC call history, waits for rendering to settle and requests garbage collection. At cycles 5, 25, 45 and 65 both starting revisions retained three documents, 1,058 DOM nodes and 246 event listeners. With both lockfiles freshly installed, used JavaScript heap rose by 1.50 MB on v0.5.3 and 1.48 MB on the starting branch over those samples. This measures the fixture's renderer on one host. Native-process memory, long-lived real accounts and attachments need separate measurements.

The production Vite builds of v0.5.3 and the starting branch both warn about the main chunk exceeding 500 kB. The uncompressed main JavaScript files were 919,632 and 921,625 bytes respectively, and 934,869 bytes on the repaired checkout. Both builds also report that the updater’s dynamic import of Tauri's window module shares a chunk with the window controls’ static import. These are existing packaging observations for startup profiling. The measured keyboard, list and Settings interactions occur after application startup.

### Where future changes need joint review

- **Rules and sync.** Follow a new arrival from the IMAP fetch through SQLite state, rule selection, queued actions and notification claims. A01 crossed these boundaries even though individual matching and notification tests passed. Include an overlapping rule on the page boundary and an account with no pending mail.
- **Connection recovery.** Exercise the identity-reset transaction against the same persisted queue states the Settings panel can display and dismiss. The review snapshot and the transaction need to refer to the same version of an operation.
- **Search and files.** Test native-to-React handoffs on both sides of listener registration, query edits and unmounts. Mock IPC should enforce the same scope, continuation rules and token lifetime as the native command.
- **Migrations and counts.** Start upgrade fixtures with data the historical release could actually write. Cover both the local-count fallback and authoritative STATUS counts on a populated account. Measure SQLite work as well as correctness at small fixture sizes.
- **Coverage infrastructure.** Keep source-only checks in the suite without requiring an app document. Preserve the assertion that navigated Postal Snap pages are instrumented. Ordinary browser success cannot establish merged coverage. The 0.5.4 diagnostic found 139 configured browser cases using the base runner directly, and successful actions in an earlier document were missing after a reload.

Flatpak rewrites the desktop entry at install time. Its file-forwarding mechanism gives the application access to files selected by the user through the document portal. The desktop file passed Debian’s desktop-file-utils 0.26 validator. AppStream 0.16.1 accepted the metadata with one informational message for the newer developer tag. An independent source-derived native argv probe read an ordinary file and an escaped local file URI and preserved a non-UTF-8 Unix argument byte-for-byte. Installed portal delivery remains a Linux-host check. [Flatpak desktop conventions](https://docs.flatpak.org/en/latest/conventions.html) and [command reference](https://docs.flatpak.org/en/latest/flatpak-command-reference.html).
