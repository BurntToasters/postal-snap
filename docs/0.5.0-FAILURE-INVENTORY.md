# 0.5.0 failure inventory

Write regression scenarios before production changes. Synthetic data only. Artifacts live in `artifacts/0.5.0/`.

Settled defaults (override before the matching beta ships):

- The undo window is about 8 seconds and pauses while the notice has hover or focus.
- Mod+K opens the command palette everywhere except inside the composer editor, where it inserts a link.
- IMAP `ID` is sent only when advertised and carries the client name, never the version.
- The all-inboxes badge sums the existing Inbox unread count for each account; it does not create a unified mail view. Muted-thread exclusion applies to received-sender suggestions.

## Remaining integration failures to prevent

Badge scope, received-sender suggestions, and SettingsDialog extraction are awaiting the final manager integration gate. Do not record these cases as passed until that gate completes.

### Settings state extraction

- Changing tabs loses account, alias, signature, or filter-rule edits.
- The close or tab-change guard omits dirty rich-signature HTML.
- Extracted effects repeat account, rule, cache, or updater requests on every render.
- A late response updates a removed account or a closed dialog.
- A failed save clears edits, leaves a busy flag set, or changes rollback behavior.
- Account removal changes the last-account setup route or outbox confirmation.
- Password state survives an account change or a completed update.
- Threat-blocking confirmation, import/export, and cache cleanup lose their existing guards.
- Keyboard tab navigation, Settings search, and focus restoration change after extraction.
- An extracted hook creates a second settings-save queue instead of using the shared queue.

### Badge and received-sender suggestions

- The default badge changes from the active Inbox, or all-Inboxes mode includes other folders.
- An obsolete count response overwrites a newer account, scope, or sync result.
- Removing an account leaves its count in the badge.
- Invalid or missing saved badge scope changes legacy settings or portable import behavior.
- Received senders displace explicit sent history, duplicate addresses, or escape the result limit.
- Suggestions expose another account, the user's own addresses or aliases, blocked senders, muted threads, Junk, Trash, or noreply senders.
- Prefix wildcard escaping, valid-address filtering, or the read-only database boundary regresses.

### Recovery and large text

- Recovery chooses an unrelated saved draft or accepts a late save from an older composer session.
- A recovered pane focuses a hidden or disabled control.
- A recovery dialog loses focus containment, Escape handling, or an interactive fallback outside the inert viewport.
- At 200% text, an avatar clips its initials or a Composer footer hides the editable body.
