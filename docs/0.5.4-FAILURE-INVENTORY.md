# 0.5.4 failure inventory

List failure modes before changing isolated code. Synthetic data only. Artifacts live in `artifacts/0.5.4/`.

## A. Schema v46 and Provider Identity

| Case | Failure | Evidence |
| ---- | ------- | -------- |
| A1 Legacy `provider_id` backfill | Upgrading from v45 leaves `accounts.provider_id` NULL or misclassifies `icloud`, `protonBridge`, Fastmail, Yahoo, AOL, Zoho, GMX, or mailbox.org accounts | Rust v45->v46 migration test |
| A2 Watermark backfill | Upgrading from v45 leaves `mailboxes.synced_max_uid` NULL when cached messages exist, causing a full re-sync from UID 1 | Rust v45->v46 migration test |
| A3 All Mail flag backfill | Upgrading from v45 misses `[Gmail]/All Mail` or marks `Archive` as `is_all_mail = 1` | Rust v45->v46 migration test |
| A4 Custom-domain identity preservation | Updating `imap_host` in Connection settings keeps an obsolete `provider_id` or clears a user-chosen preset unexpectedly | Rust DB tests |

| Case | Failure | Evidence |
| ---- | ------- | -------- |
| B1 Gmail vs Outlook | Gmail is wrongly blocked as OAuth-only or uses `ProviderKind::Gmail` (which requires OAuth); Outlook.com is wrongly allowed password setup | Rust `providers.rs` tests, Playwright onboarding |

| B3 Fastmail custom domain MX | MX match on `messagingengine.com` omits the primary-username hint | Rust `providers.rs` tests, Playwright onboarding |
| B4 RFC 6186 SRV security | SRV discovery accepts `.` target, port 0, private/local DNS name, or non-ASCII lookalike host | Rust `providers.rs` tests |
| B5 Autoconfig CRAM-MD5 & URLs | Autoconfig accepts `password-encrypted` without LOGIN/PLAIN support, or ever populates `app_password_url` from XML | Rust `providers.rs` tests |
| B6 Password normalization | Spaces or zero-width chars are kept in Gmail/Yahoo/AOL/Fastmail/Zoho/StartMail app passwords, or internal spaces are stripped from standard passwords | Rust `validate.rs` tests |
| B7 Error classification & redaction | Non-pinned SMTP 535 classifies as `connectionFailed`; blank password classifies as `authenticationFailed`; invalid Bridge cert classifies as `connectionFailed`; TLS cert errors drop `FailureKind::Certificate` or leak server text; missing vault entry retries as `offline` instead of `authFailed` | Rust `ipc_error`, `send`, `failure`, `credentials` tests |
| B8 Zeroization & Windows persistence | Early `take_validated_setup` validation failure skips password zeroization; iCloud CalDAV 401 returns empty aliases instead of auth failure; iCloud follow-up URL accepts non-443 ports | Rust `validate`, `icloud`, `oauth` tests |
| B9 Re-auth recovery | `update_account_password` fails to emit `wake::CREDENTIALS`; changing only IMAP port/TLS wipes local cache; stale `account.error` stays visible after `idle` sync | Rust tests, Playwright Settings re-auth |

## C. Sync, Search Watermarks, SMTP Timeouts & Parsing

| Case | Failure | Evidence |
| ---- | ------- | -------- |
| C1 Search watermark pollution | Server search hit for UID > `synced_max_uid` skips intermediate unsynced mail, or a hit for UID < `backfill_uid` breaks "Load older messages" | Rust `sync` / `db` tests |
| C2 CONDSTORE `HIGHESTMODSEQ 0` | Mailbox reporting `HIGHESTMODSEQ 0` or `NOMODSEQ` skips all future flag scans even when `UNSEEN` changes | Rust `sync` tests |
| C3 Junk training desync | A timed-out or broken `STORE` during junk training releases a desynchronized pooled session | Rust `folders` tests |
| C4 Custom Trash & non-UTF-8 `References:` | Assigning a custom Trash folder blocks permanent deletion; non-UTF-8 body bytes break `References:` parsing or read 50 MiB BLOBs | Rust `db` tests |
| C5 Rules v2 ordering & notify | Move-before-Flag drops flags; Move+Notify breaks tap-to-open; one missing-folder rule prevents clearing `ARRIVAL_RULE_PENDING` on unrelated mail | Rust `commands/sync` & `db` tests |
| C6 Remote drafts & mbox | Plain-text remote drafts import as `<p></p>` with `include_signature=true`; mbox import stamps `INTERNALDATE` as `NOW` or aborts whole import on one bad message | Rust `remote_drafts` / `append` tests |
| C7 Non-ASCII IMAP search | Non-ASCII search emits invalid 8-bit quoted string instead of RFC 3501 literal | Rust `search_query` tests |
| C8 Offline replay tolerances | Replay rejects valid server messages whose `RFC822.SIZE` differs slightly from `BODY.PEEK[]` or when unsolicited `FETCH` arrives | Rust `folders` tests |
| C9 Apple Mail & partial bodies | Multi-segment `multipart/mixed` truncates after inline attachment; HTML-only partial message loses preview/FTS; strict `Date:` parse mismatches full parse | Rust `parse` tests |
| C10 SMTP & APPEND timeouts | Non-pinned SMTP `DATA` times out at 20s `CONNECT_TIMEOUT` instead of scaling with payload; read receipts omit `Date:` | Rust `send` tests |
| C11 Transient IMAP login refusal | `[INUSE]`, `[SERVERBUG]`, `[OVERQUOTA]`, or `"too many connections"` parks account permanently as `authFailed` | Rust `watch` tests |
